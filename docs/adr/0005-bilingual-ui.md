# The UI switches between English and Chinese

The control plane and Status Page are bilingual. The first paint is English; the Operator or Visitor can switch to Chinese. README can still lead with English for recruiters.

English-only was rejected: the Operator works in Chinese and the public demo should too. A Chinese-only UI was rejected: an international recruiter opening the Status Page should not hit a wall. Detecting the browser language was rejected: the default must be predictable for screenshots and recruiter links.

This is extra product surface (every label, every Notification subject). Adding it later means retrofitting strings; the first screens should already be keyed.
