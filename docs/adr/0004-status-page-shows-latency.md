# The Status Page is a full public face, including latency

A typical public status page hides latency. Pulse shows current state, a response-time chart, recent Incidents, and 90-day Availability for each Public Monitor so the Visitor demo matches the Operator console and still reads as a status page.

The cost is leaking timing detail. That is accepted: this instance has one Operator, and the public page is part of the portfolio.
